# Contexto eDisk

## Recuperar

1. Leia `docs/CONTEXTO_ATUAL.md`.
2. Consulte `docs/PLANO_DESENVOLVIMENTO.md` somente para stack, arquitetura, módulos ou próximas entregas.
3. Verifique no código fatos que possam ter mudado.

## Atualizar

Atualize `docs/CONTEXTO_ATUAL.md` somente após marco duradouro, decisão, nova migração, bloqueio ou mudança da próxima etapa.

Registre apenas estado atual, decisões vigentes, problemas conhecidos e próximo passo. Substitua conteúdo obsoleto; não acumule histórico nem duplique o plano.

Nunca registre credenciais, PII, suposições ou validações não executadas. Esta skill não autoriza código, testes, builds, migrações, commits ou sincronização externa.
